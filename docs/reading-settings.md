# Настройки чтения

`settings/ReadingSettings.kt` хранит независимые от прохождения настройки:

- `textScale`: множитель размера реплик, вариантов выбора и журнала, 0.85–1.5; системный масштаб шрифта продолжает применяться.
- `reduceMotion`: отключение переходов и движения камеры.
- `soundEnabled`: общий выключатель аудио.
- `volume`: общая громкость 0–1, по умолчанию 0.7; выключение звука сохраняет выбранную громкость.

`rememberReadingSettingsController()` создаёт контроллер приложения. Его наблюдаемое `settings` передаётся экрану чтения и аудио; `SettingsDialog(settings, onSettingsChange, onDismiss, error)` предоставляет прокручиваемый диалог с предпросмотром размера текста. Слайдеры сохраняют значение после отпускания.

Данные записываются в отдельный `reading-settings.json`: Android использует AtomicFile во внутреннем каталоге приложения, iOS — атомарную запись в Application Support/Storyteller. Сброс или создание нового прохождения не меняют эти настройки. Контроллер обновляет опубликованное состояние после успешной записи. Ошибки чтения и записи отображаются в диалоге; неудачная запись оставляет предыдущее состояние и допускает повторную попытку.

Отсутствующие поля получают значения по умолчанию, неизвестные поля игнорируются, числа ограничиваются допустимым диапазоном. Повреждённая запись не блокирует чтение: используются стандартные настройки, которые можно сохранить заново.

Host-тесты проверяют восстановление, совместимость полей, повреждённые данные, нормализацию и отказ записи с повторной попыткой. Перед выпуском нужна проверка максимального размера текста и системного масштаба на небольшом устройстве; а также переходов при включённом уменьшении анимаций. Авточтение и пропуск прочитанного остаются следующей итерацией.
