# План: Сцены с изображениями и визуальные эффекты в Storyteller

## Цель
Переработать формат описания историй: **сцены содержат ноды**. Сцена = фоновое изображение + свои ноды; нода несёт эффекты (камера пан/зум, спрайты персонажей). Переход на новую сцену задаётся у ноды/выбора (`nextSceneId`/`targetSceneId` + `nextNodeId`/`targetNodeId`), с которой продолжается история; эффект входа в новую сцену (fade) **настраивается на ноде/выборе, запускающем сцену** (`nextSceneStartEffect`/`targetSceneStartEffect`), а не автоматически. Старый story.json мигрирует на новый формат (обратная совместимость не требуется — решено пользователя).

## Решения пользователя
- Сцены — сущность, **владелец нод**: `scenes` map, каждая сцена содержит свой `nodes` map.
- Смена сцены — явная: у `Choice` — `targetSceneId`, у `DialogueNode` — `nextSceneId` (вместе с целевой нодой).
- Эффекты v1: камера (пан/зум), спрайты персонажей, fade — **только если указан отправителем** в `nextSceneStartEffect`/`targetSceneStartEffect` (по умолчанию `NONE` — мгновенная смена).
- Изображения хранятся в ресурсах приложения (composeResources, `files/`), как сейчас story.json.
- Формат story.json переделывается; текущий сценарий переписывается.

## Дизайн формата сценария

```json
{
  "id": "forest_mystery",
  "title": "Таинственный лес",
  "description": "Приключение в таинственном лесу.",
  "characters": [
    { "id": "narrator", "name": "Рассказчик" },
    { "id": "old_man", "name": "Старик", "spriteResource": "files/characters/old_man.png" }
  ],
  "startSceneId": "forest",
  "startNodeId": "start",
  "scenes": {
    "forest": {
      "id": "forest",
      "backgroundResource": "files/scenes/forest.png",
      "nodes": {
        "start": {
          "id": "start", "characterId": "narrator",
          "text": "Вы просыпаетесь в темном лесу...",
          "cameraStart": { "focusX": 0.25, "focusY": 0.6, "zoom": 1.4 },
          "camera": { "focusX": 0.75, "focusY": 0.5, "zoom": 1.0 },
          "cameraDurationMs": 4000,
          "choices": [
            { "id": "choice_left",  "text": "Пойти налево на звук воды.",
              "targetSceneId": "river", "targetNodeId": "river_bank", "targetSceneStartEffect": "FADE" },
            { "id": "choice_right", "text": "Пойти направо на мерцающий свет.",
              "targetSceneId": "cabin", "targetNodeId": "cabin_greet", "targetSceneStartEffect": "FADE" }
          ]
        }
      }
    },
    "river": {
      "id": "river",
      "backgroundResource": "files/scenes/river.png",
      "nodes": {
        "river_bank": { "...": "пан вправо, выборы внутри сцены river" },
        "drowned":    { "nextSceneId": "ending", "nextNodeId": "game_over", "nextSceneStartEffect": "FADE" },
        "bridge":     { "nextSceneId": "cabin",  "nextNodeId": "cabin_greet", "nextSceneStartEffect": "FADE" }
      }
    },
    "cabin": {
      "id": "cabin",
      "backgroundResource": "files/scenes/cabin.png",
      "nodes": {
        "cabin_greet": {
          "id": "cabin_greet", "characterId": "old_man",
          "text": "Добро пожаловать, путник...",
          "camera": { "focusX": 0.5, "focusY": 0.5, "zoom": 1.2 },
          "stageCharacters": [ { "characterId": "old_man", "position": "CENTER" } ],
          "choices": [ ... ]
        },
        "fire": { "nextSceneId": "ending", "nextNodeId": "game_over", "nextSceneStartEffect": "FADE" }
      }
    },
    "ending": {
      "id": "ending",
      "backgroundResource": "files/scenes/ending.png",
      "nodes": { "game_over": { "id": "game_over", "characterId": "system", "text": "Конец.", "choices": [] } }
    }
  }
}
```

### Семантика переходов
- `Choice.targetSceneId` / `DialogueNode.nextSceneId` — опциональны: если заданы, происходит смена сцены + переход на `targetNodeId`/`nextNodeId` **внутри этой сцены**; если нет — переход внутри текущей сцены. Ссылок на ноду другой сцены без указания сцены не допускается (node id уникальны в пределах сцены).
- `DialogueNode.nextSceneStartEffect` / `Choice.targetSceneStartEffect` (`NONE` по умолчанию, `FADE`): эффект входа в новую сцену. Применяется только при реальной смене сцены; при переходе внутри той же сцены игнорируется.
- `visitedNodes` в `GameState` хранит составные ключи `"sceneId/nodeId"` (движок формирует их сам).
- При смене сцены камера снапается к `cameraStart ?: camera` новой ноды (плавный пан между сценами невозможен).

### Семантика эффектов ноды (внутри сцены)
- `camera` — целевое состояние камеры: `focusX/focusY` (0..1 — нормализованная точка фона в центре вьюпорта), `zoom` (>=1, 1 = «покрыть» вьюпорт). Если null — камера не меняется.
- `cameraStart` — опциональная стартовая точка камеры (для управляемого панорамирования). По умолчанию анимация идёт от текущего положения камеры.
- `cameraDurationMs` — длительность анимации камеры (по умолчанию 700 мс; большое значение = медленный cinematic pan).
- `stageCharacters` — кто из персонажей на сцене и где (`LEFT/CENTER/RIGHT`, `scale`, `visible`). `null` — наследуется от предыдущей ноды.

## Изменения по файлам

### 1. Модели (`shared/src/commonMain/kotlin/com/radmir/storyteller/models/`)
- **Нов. `Scene.kt`**: `@Serializable data class Scene(id: String, backgroundResource: String, nodes: Map<String, DialogueNode> = emptyMap())`.
- **Нов. `CameraView.kt`**: `@Serializable data class CameraView(focusX: Float = 0.5f, focusY: Float = 0.5f, zoom: Float = 1f)`.
- **Нов. `StageCharacter.kt`**: `@Serializable data class StageCharacter(characterId: String, position: StagePosition = CENTER, scale: Float = 1f, visible: Boolean = true)` + `@Serializable enum class StagePosition { LEFT, CENTER, RIGHT }`.
- **Нов. `SceneStartEffect.kt`**: `@Serializable enum class SceneStartEffect { NONE, FADE }`.
- **`StoryScript.kt`**: `startNodeId` + **нов. `startSceneId: String`**; `nodes` заменяется на `scenes: Map<String, Scene>`.
- **`DialogueNode.kt`**: удалить `imageResource`; добавить `camera: CameraView?`, `cameraStart: CameraView?`, `cameraDurationMs: Long?`, `stageCharacters: List<StageCharacter>?`, `nextSceneId: String?`, `nextSceneStartEffect: SceneStartEffect?` (все с дефолтом null).
- **`Choice.kt`**: + `targetSceneId: String? = null`, `targetSceneStartEffect: SceneStartEffect? = null`.
- **`Character.kt`**: переименовать `portraitResource` → `spriteResource` (путь вида `files/characters/old_man.png`).
- **`GameState.kt`**: + `currentSceneId: String`.

### 2. Движок (`engine/StoryEngine.kt`)
- `initialize`: `GameState(currentSceneId = script.startSceneId, currentNodeId = script.startNodeId)`.
- Внутренний хелпер `nodeIn(sceneId, nodeId)`; `getCurrentScene()`.
- `getCurrentNode`: `script.scenes[currentSceneId]?.nodes?.get(currentNodeId)`.
- `selectChoice`: целевая сцена = `choice.targetSceneId ?: currentSceneId`; валидация существования ноды в ней; `visitedNodes` + `"sceneId/nodeId"` текущей позиции; новый `GameState(currentSceneId = целевая, currentNodeId = choice.targetNodeId, ...)`.
- `advance`: аналогично с `nextSceneId ?: currentSceneId` (переход только если `nextNodeId != null`, как сейчас).

### 3. ViewModel (`viewmodel/StoryViewModel.kt`)
- Нов. `SceneUiState` (в `viewmodel/`): `scene: Scene`, `cameraTarget: CameraView`, `cameraStart: CameraView?`, `cameraDurationMs: Long`, `stage: List<StageCharacter>`, `enterEffect: SceneStartEffect`, `nodeId: String`.
- `enterEffect` вычисляется из источника перехода: при `selectChoice` — `choice.targetSceneStartEffect` (если сцена реально сменилась, иначе `NONE`); при `advance` — `node.nextSceneStartEffect`; при `loadStory` — `NONE`.
- VM держит `_currentScene: StateFlow<Scene?>`; `stage` наследуется при `stageCharacters == null`. Пересчёт в `loadStory`/`selectChoice`/`advance`.

### 4. UI — рендер сцены (нов. `screens/scene/`)
- **`ResourceImage.kt`**: `@Composable rememberResourceImageBitmap(path: String): ImageBitmap?` — `Res.readBytes(path)` + `org.jetbrains.skia.Image.makeFromEncoded(...).asImageBitmap()`, кэш `ConcurrentHashMap<String, ImageBitmap>`; асинхронно через `LaunchedEffect`, до загрузки — null.
- **`CameraTransform.kt`** (чистая математика, тестируемая): `fun cameraTransform(camera: CameraView, container: Size, image: Size): CameraTransform` — `scale = coverScale * zoom`, offset = `containerCenter − focus * imageSize * scale`, клампинг offset'ов, чтобы фон всегда закрывал вьюпорт (при zoom >= 1).
- **`SceneBackground.kt`**: `@Composable SceneBackground(scene, cameraTarget, cameraStart, durationMs, enterEffect, nodeId)` — `Box(Modifier.clipToBounds())` + `Image(ContentScale.Crop)` c `Modifier.graphicsLayer { scaleX/scaleY/translationX/translationY }` из `CameraTransform`; камера — `remember(nodeId) { Animatable(...) }`: при `enterEffect != NONE` (смена сцены) `snapTo(cameraStart ?: cameraTarget)`, иначе `animateTo(cameraTarget, tween(durationMs))` (при `cameraStart != null` сначала `snapTo(cameraStart)`); fade — `animateFloatAsState` alpha 0→1 (500 мс) **только при `enterEffect == FADE`**, при `NONE` фон показывается сразу.
- **`CharacterSprite.kt`**: спрайт `Image` с высотой ~55% вьюпорта, выравнивание по низу, `Alignment` по `StagePosition`, `Modifier.graphicsLayer { alpha/scaleX/scaleY }` для `visible`/`scale`; alpha-анимация появления.
- **`StoryScreen.kt`** — редизайн на слои:
  ```
  Box(fillMaxSize, чёрный фон) {
    SceneBackground(...)
    stage.forEach { CharacterSprite(...) }        // Box со спрайтами
    DialogueOverlay(...)                          // нижняя панель
  }
  ```
  `DialogueOverlay` (в StoryScreen.kt или нов. `screens/scene/DialogueOverlay.kt`): спикер + текст + кнопки choices/«Далее»/«Конец истории» на полупрозрачной подложке (`Color.Black.copy(alpha = 0.6f)`), существующая логика кнопок/`viewModel` сохраняется.

### 5. Ресурсы
- Нов. каталоги: `shared/src/commonMain/composeResources/files/scenes/` и `.../files/characters/`.
- Плейсхолдеры генерируются PowerShell + GDI+ (System.Drawing, доступен в Windows PowerShell 5.1), без новых зависимостей:
  - `forest.png`, `river.png`, `cabin.png`, `ending.png` — 1600×900, градиенты с подписью имени сцены (фон шире вьюпорта — для наглядности панорамирования).
  - `old_man.png` — 400×800, фигура-силуэт на прозрачном фоне (PNG с альфой).
- Генерация выполняется один раз в implementation-фазе; в git попадают только PNG.

### 6. `story.json` — миграция на новый формат
- Переписать сценарий «Таинственный лес» по графу:
  - `forest`: `start` (медленный пан, `cameraStart` слева zoom 1.4 → `camera` справа, 4000 мс) → выборы в сцены `river`/`cabin` (с `targetSceneStartEffect: FADE`).
  - `river`: `river_bank` (пан вправо) → выборы внутри сцены (`drowned`/`bridge`); `drowned` → `nextSceneId: ending` + `FADE`; `bridge` → `nextSceneId: cabin` + `FADE`.
  - `cabin`: `cabin_greet` (`stageCharacters` со стариком CENTER) → выборы внутри сцены (`fire`/возврат `forest.start`); `fire` → `nextSceneId: ending` + `FADE`.
  - `ending`: `game_over`.

### 7. Тесты (`shared/src/commonTest/kotlin/com/radmir/storyteller/`)
- Нов. `SceneModelsTest.kt`: kotlinx-декодирование JSON нового формата (сцены с нодами, camera, stageCharacters, nextSceneStartEffect, дефолты).
- Нов. `StoryEngineTest.kt` (с фиктивным `StoryRepository` через `loadScript(json)`): инициализация по `startSceneId`/`startNodeId`; выбор с `targetSceneId` меняет сцену и ноду; выбор без `targetSceneId` остаётся в сцене; `advance` с `nextSceneId` и без; `visitedNodes` содержит составные ключи.
- Нов. `CameraTransformTest.kt`: клампинг offset'ов, центрирование фокуса, zoom > 1.
- `SharedCommonTest.kt` не трогаем.

## Верификация
- `./gradlew :shared:allTests` — юнит-тесты (сериализация, движок по сценам, математика камеры).
- `./gradlew :androidApp:assembleDebug` — сборка без ошибок.
- Ручной прогон на Android (`:androidApp:installDebug`): «Open Stories» → «Start Story»:
  - сцена forest отображается, медленный пан на `start` (≈4 с);
  - выбор «налево» → fade в сцену river; выбор «направо» → fade в cabin, старик появляется по центру;
  - `bridge` → fade в cabin; `drowned`/`fire` → fade в ending, «Конец истории»;
  - переходы внутри сцены — без fade (мгновенная смена фона);
  - выборы/«Далее» работают поверх сцены, текст читаем (подложка диалога).
- До загрузки PNG — чёрный фон без крашей (отсутствующий файл = нет изображения, не краш).
