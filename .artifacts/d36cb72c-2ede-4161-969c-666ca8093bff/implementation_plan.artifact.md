# Прототип движка визуальной новеллы

Этот план описывает создание базового движка для игры в жанре визуальная новелла на Kotlin Multiplatform (KMP). Основная цель — создать систему обработки сценариев, состояний и условий выбора, которую можно будет визуализировать с помощью Compose Multiplatform.

## User Review Required
> [!IMPORTANT]
> Мы начинаем с реализации логики в `commonMain`. Это обеспечит кроссплатформенность игры. UI будет реализован позже на основе этой логики.

## Proposed Changes

### Core Models & Serialization
Разработка базовых моделей данных в `shared/src/commonMain/kotlin/com/radmir/storyteller/models/`.

#### [NEW] DialogueNode.kt
Определяет узел диалога: ID, текст, имя персонажа, список вариантов выбора.

#### [NEW] Choice.kt
Определяет вариант выбора: текст, ID целевого узла, условия активации.

#### [NEW] GameState.kt
Хранит текущее состояние игры: текущий узел, словарь переменных (например, очки отношений), история.

#### [NEW] StoryScript.kt
Контейнер для всего сценария, парсинг из JSON.

---

### Story Engine Logic
Реализация основного функционала управления игрой.

#### [NEW] StoryManager.kt
Сервисный класс для управления сценарием:
- Переход между узлами.
- Проверка условий выбора.
- Обновление переменных состояния.

#### [NEW] StoryRepository.kt
Простая прослойка для получения данных сценария.

---

### UI Layer (Compose Multiplatform)
Визуализация движка.

#### [NEW] StoryViewModel.kt
ViewModel для связи UI и `StoryManager`.

#### [MODIFY] App.kt (или новый экран)
Основной экран игры с компонентами:
- `DialogueBox`: Вывод текста.
- `ChoiceList`: Динамический список кнопок выбора.
